# 个人博客 — 周报生成模板

> 复制下方对应类型的模板，填入 `data/xxx-weekly.js` 数组**最前面**即可。

---

## 通用字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| `id` | `YYYY-MM-DD`，唯一标识 | `"2026-08-09"` |
| `date` | 同上，显示用 | `"2026-08-09"` |
| `title` | 标题，含编号 + 一句话主题 | `"科技周报 #34 · AI 算力新进展"` |
| `tags` | 3~4 个标签 | `["AI", "开源", "算力"]` |
| `summary` | 列表展开摘要，80~120 字 | |
| `content` | 正文，支持 Markdown（`##` `**` `|` 表格 `>` 引用 `-` 列表 `` \`\`\` `` 代码块） |

> ⚠️ content 内**禁止**使用英文双引号 `"`（会破坏 JS 字符串），统一用中文引号 `「」` 或直接避免。

```js
  content: `## 本周关注

> 一句话概述本周核心趋势或重要事件。

- **事件1**：说明
- **事件2**：说明

## 二、xxx 新进展

| 项目 | 要点 | 影响 |
|------|------|------|
| **项目A** | 说明 | 影响评估 |
| **项目B** | 说明 | 影响评估 |

## 三、本周推荐文章 / 资源

1. [文章标题](链接) — 一句话介绍
2. [文章标题](链接) — 一句话介绍

- 关注点1
- 关注点2`,
}
```

## 使用方式

1. 把上面的模板 + 你的素材给 AI，生成完整条目
2. 复制生成的内容，粘贴到 `data/tech-weekly.js`（或 `work-weekly.js` / `study-weekly.js` / `stock-weekly.js`）数组**最前面**
3. 运行 `bash deploy.sh` 推送上线

> 💡 给 AI 的 prompt 示例：
> ```
> 根据以下模板和我的素材，生成一条新的周报条目。
> 模板：[粘贴上方对应模板]
> 我的素材：[粘贴本周素材]
> 注意：content 内不要使用英文双引号 "，用中文引号「」替代，不要输出文件路径。
> ```
